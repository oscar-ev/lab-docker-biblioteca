    Abra um terminal (no Windows: PowerShell) e confira:

    O que é Docker?É como uma “caixa” que leva o programa junto com tudo que ele precisa (Python, bibliotecas, banco). Assim ninguém precisa instalar Python ou MySQL na máquina, e o famoso “no meu PC funciona” deixa de existir.

    Banco de dados: o script SQL

    Tabelas usuarios e livros

    Esse arquivo roda automaticamente na primeira vez que o MySQL sobe. Ele cria as tabelas e já insere o usuário administrador.

    Entender linha a linha
    CREATE TABLE
    Cria uma tabela, que é como uma planilha: colunas fixas e uma linha por registro.
    INT AUTO_INCREMENT
    Número que o banco gera sozinho: 1, 2, 3… Serve de identificador.
    PRIMARY KEY
    A coluna que identifica cada linha de forma única. Não pode repetir.
    VARCHAR(150)
    Texto de até 150 caracteres.
    NOT NULL
    O campo é obrigatório.
    UNIQUE
    Não deixa existir dois usuários com o mesmo nome.
    INSERT INTO
    Adiciona uma linha na tabela. Aqui criamos o admin e dois livros de exemplo.
    Atenção: guardar senha em texto puro é só para fins didáticos. Em sistemas reais a senha é guardada como hash (veja o desafio extra no final).

    O servidor web em Python

    Rotas de login, logout, listar, cadastrar e excluir

    Este é o coração do sistema. Cada @app.route é um “endereço” do site.

    Entender as partes principais
    os.getenv(...)
    Lê configurações que o docker-compose passa (endereço do banco, usuário, senha). Assim não “chumbamos” senha no código.
    @app.route("/login")
    Quando alguém abre /login, o Flask chama a função logo abaixo.
    methods=["GET","POST"]
    GET = abrir a página. POST = enviar o formulário.
    %s
    Espaço reservado para valores. O pymysql preenche com segurança, o que evita SQL Injection. Nunca monte SQL juntando textos com +.
    session["usuario"]
    Memória do navegador que diz “esta pessoa já fez login”.
    con.commit()
    Confirma a gravação no banco. Sem ele, o INSERT/DELETE não é salvo.
    flash(...)
    Mostra uma mensagem rápida na próxima página.
    redirect(...)
    Manda o navegador para outra página.
    host="0.0.0.0"
    Faz o servidor aceitar conexões de fora do contêiner (senão você não conseguiria abrir no navegador).
    Por que o host do banco é “db”?Dentro do Docker Compose, cada serviço é encontrado pelo seu nome. O serviço do MySQL se chama db, então o Python acessa o banco pelo endereço db, e não por localhost.

    As páginas HTML (templates)

    Três arquivos dentro de app/templates/

    O Flask usa o Jinja: HTML com “buracos” como {{ livro.titulo }}, que o Python preenche com dados do banco.

    Molde comum: estilo e mensagens. As outras páginas “herdam” dele com {% extends %}.

    O name de cada campo é o que o Python lê em request.form["usuario"].

    {% for %} repete a linha da tabela para cada livro vindo do banco.

    ConfiraOs três arquivos precisam estar dentro de app/templates/. O Flask procura as páginas exatamente nessa pasta.
    7

    Dockerfile: a receita da imagem

    Como montar o contêiner do Python

    O arquivo se chama Dockerfile, sem extensão nenhuma (cuidado com o Windows criando Dockerfile.txt).

    Entender linha a linha
    FROM
    Imagem de partida: um Linux pequeno que já vem com Python 3.12.
    WORKDIR /app
    Pasta de trabalho dentro do contêiner.
    COPY requirements.txt .
    Copia só a lista de bibliotecas primeiro. Assim o Docker reaproveita a instalação quando você muda apenas o código.
    RUN pip install
    Instala as bibliotecas durante a construção da imagem.
    COPY . .
    Copia o resto do código (app.py e templates).
    CMD
    Comando executado quando o contêiner liga.
    8

    docker-compose.yml: juntando tudo

    Dois serviços: db e web

    Fica na pasta raiz biblioteca/. Em YAML a indentação (espaços) importa: use 2 espaços e nunca TAB.

    Entender as partes
    image: mysql:8.0
    Usa a imagem oficial do MySQL, pronta. Não precisa de Dockerfile.
    environment
    Variáveis de configuração: nome do banco, usuário e senha.
    volumes (init.sql)
    Coloca nosso script na pasta que o MySQL executa ao iniciar pela primeira vez.
    dados_mysql
    Volume nomeado: os dados continuam salvos mesmo se o contêiner for apagado.
    healthcheck
    Teste que diz quando o MySQL está realmente pronto.
    depends_on … service_healthy
    O site só liga depois que o banco passou no healthcheck. Evita erro de conexão.
    build: ./app
    Monta a imagem usando o Dockerfile da pasta app.
    ports "5000:5000"
    Porta do seu PC : porta do contêiner. É o que permite abrir localhost:5000.

    Teste rápido: o que acontece se você trocar para "8080:5000"?

    Deu erro? E desafios extras

    Os problemas mais comuns da turma

    “port is already allocated” / porta 5000 em uso

    Outro programa usa a porta 5000 (no Mac, o AirPlay costuma usar). Troque no compose para "5001:5000" e abra localhost:5001.

    “Cannot connect to the Docker daemon” / “docker: command not found”

    O Docker Desktop não está aberto ou não terminou de iniciar. Abra e espere o status “running”.

    “TemplateNotFound: login.html”

    A pasta precisa se chamar exatamente templates (minúsculo, com “s”) e estar dentro de app/.

    Alterei o init.sql e nada mudou

    O script só roda quando o banco é criado pela primeira vez. Para recriar do zero (apaga os dados!):

    Alterei o app.py e o site não mudou

    O código é copiado para a imagem no build. Pare com Ctrl+C e rode de novo docker compose up --build.

    Erro de indentação no YAML (“mapping values are not allowed”)

    Confira os espaços. Use o botão Copiar deste roteiro em vez de digitar.

    Acentos aparecem estranhos (ex.: “OrgulhoÃ”)

    Salve o init.sql em UTF-8 (VS Code: canto inferior direito) e recrie o banco com docker compose down -v.

    Desafios extras (vale ponto!)

    1. Editar livro: crie uma rota /livros/<id>/editar com um formulário preenchido e um UPDATE livros SET … WHERE id=%s.
    2. Busca: adicione um campo de pesquisa que use WHERE titulo LIKE %s com o valor "%" + termo + "%".
    3. Nova coluna: adicione genero VARCHAR(50) na tabela e no formulário.
    4. Senha segura: use generate_password_hash e check_password_hash do pacote werkzeug.security (já vem com o Flask).
    5. phpMyAdmin: adicione um terceiro serviço no compose com a imagem phpmyadmin na porta 8080 para ver o banco pelo navegador.
